# Showcase image provenance

The 1.0 scenes are browser screenshots of real components. Text, inputs, buttons, checklists, charts, simulation canvases, and the expanded pane are rendered by the plugin. No UI controls were redrawn by AI, and no multiple-page collage was used.

The real model material comes from completed native GPT-6.1 Sol acceptance runs before release, with the original answers preserved. To improve framing, those answers were replayed verbatim in an isolated DSH 0.2.1-alpha.2 conversation; no additional external model calls were made. The “interaction test model” label in the screenshots identifies the local replay provider, not the author of the answers. All native scenes were captured in isolated host conversations using public components and the actual expand entrance, without accessing active user conversations or login state.

The dinner example is rendered separately by the real components in the current source. Before capture, actual interaction confirmed that changing six guests to seven updates chicken from 1.5 to 1.75 kg, returning to six restores 1.5 kg, and checking a preparation item shows 1 / 3 completed. Quantities are illustrative estimates.

These images show interaction effects. Supported hosts, installation instructions, and the actual acceptance scope are documented on the project homepage and in the release notes. Images and public notes contain no credentials, private user data, or machine paths.
