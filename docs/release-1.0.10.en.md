# IUI 1.0.10 · DSH 0.2.1-rc.1 / rc.2

[中文](release-1.0.10.md) · [English](release-1.0.10.en.md)

## Improvements

- Artifacts follow native DSH light/dark colors, accents, fonts, and body text size.
- The intelligent-chat entry uses the native button and icon; artifact close/retry actions use native buttons.
- Existing artifact formats, storage locations, and conversation actions are preserved.

## Installation

Choose the pinned package matching the full host version. Restart the selected profile and refresh the page after updating. Keep the original DSH data directory to retain artifacts.
