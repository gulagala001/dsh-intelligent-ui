# IUI 1.0.10 · DSH 0.2.1-rc.1 / rc.2

[中文](release-1.0.10.md) · [English](release-1.0.10.en.md)

## 体验优化

- 交互作品跟随 DSH 原生明暗配色、主题色、字体与正文字号。
- 新建智能聊天入口采用宿主原生按钮与图标，作品面板的关闭和重试采用原生按钮。
- 保留已有作品格式、保存位置和会话交互方式。

## 安装

选择与完整宿主版本匹配的固定包；更新后重启对应 profile 并刷新页面。使用原 DSH 数据目录即可继续读取已有作品。
