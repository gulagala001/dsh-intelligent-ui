- Exact DSH SDK, Cordis 4.0.5, Schemastery 3.18.5, and frozen locks per host.
- Improved concurrent submission, recovery and save acknowledgments; stable table selection and numeric controls.
- Bounded scene and rendering work; existing artifact formats and saved data remain usable.
- Chat, on-demand skills, charts, forms, simulations, games, expansion, and export continue through DSH's native workflow.

Install the package matching your complete host version, then restart the selected profile and refresh the browser. Keep the existing DSH data directory. OMD is optional; no separate agent service is required.
