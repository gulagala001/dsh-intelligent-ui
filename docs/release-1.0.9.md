- 逐宿主精确匹配 DSH SDK、Cordis 4.0.5、Schemastery 3.18.5 与冻结锁。
- 改进并发提交、恢复与保存回执，修复表格选择及数字控件边界。
- 限制场景求值和渲染开销，继续读取已有组件格式与作品数据。
- 保留 Chat、按需技能、图表、表单、模拟与游戏，以及展开、导出等原生工作流。

安装完整版本匹配的包后，重启选定 profile 并刷新浏览器；保留原 DSH 数据目录。OMD 为可选插件，无需另开 agent 服务。

安装使用本仓库的 GitHub Release 工件。同名 npm 包属于其他项目。详见 [安装](../README.md#installation)、[使用说明](usage.md) 与 [许可声明](../THIRD_PARTY_NOTICES.md)。
