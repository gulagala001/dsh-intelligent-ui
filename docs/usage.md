# 使用说明

[中文](usage.md) · [English](usage.en.md)

适用于 IUI 1.0.0。安装包与完整宿主版本的对应关系见 [首页](../README.md#installation)。

## 智能聊天

鼠标移到整格“新会话”上，右侧会浮现 Chat 气泡图标。点击它后，插件创建新会话、选择智能聊天模式并继承当前模型；点击格子的其他位置继续创建普通会话。键盘聚焦时显示 Chat，可用 Tab 切换并按 Enter 创建；触屏和折叠侧栏直接显示入口。

可以直接提问，例如“做个能调整人数的周末聚餐计划”“用交互图讲讲光合作用”“给我一个分账工具”。模型会选择合适的文字和控件；只需要文字的问题仍可用文字回答。

生成过程中先呈现已有部分。控件在当前生成步骤结算并读取已保存设置后启用，避免半成品动作落到旧状态。

## 普通 agent

使用 `/intelligent-ui` 或原生 `skill({name:"intelligent-ui"})`。基础资料随 skill 正文提供；图表、表单、交互与场景资料按需读取。安装插件不会替换普通 agent 的主提示词、模型、工具循环或所有工具说明。

## 操作与恢复

数字、选择、勾选、图表筛选和游戏操作都在本地执行。明确的提交按钮将所选字段和操作说明发给原会话，继续沿用 DSH 排队、取消和恢复。

控件设置自动保存。刷新、重开和宿主重启后从原会话恢复。模拟播放在恢复后暂停，点击播放才继续；离屏、后台或关闭视图会停止。

同一作品在回答与展开页签共享设置。多个标签页发生保存冲突时，当前编辑继续保留；确认保存时合并未修改的远端字段。发生错误时先看回答底部的保存状态，再选择重试。

图表可以直接点选图形或下方数据行；聚焦图形后用方向键移动、Enter 或空格选中，Escape 取消。饼图可以切换指标并隐藏分类，图例显示数值与占比。表格排序和图表筛选在展开、收回和刷新后保留。无法区分的完全重复数据行或超长行身份，其点选仅当前视图保留。

作者为图表系列明确标注 `unit` 时，柱图、折线图、面积图和散点图按同单位组展示；例如月费“元”和容量“GB”通过“显示指标”切换，同组系列仍可分别筛选。饼图继续按单个指标展示。未标单位的旧图表保留原行为，不从名称推断单位，也不自动换算或归一数据。

窄回答中的图表、示意图和场景提供“放大图形”：以原尺寸查看标注，图形区域可独立滚动，键盘聚焦该区域后可滚动查看。点击“适应宽度”回到完整概览。放大只影响当前视图，数据、选中和播放继续保留；重开视图默认适应宽度。

内联回答与展开页签中的同一模拟共用播放与暂停；关闭其中一处后，另一处仍可继续。全部视图离屏或进入后台后暂停，重开默认暂停。

模拟和带参数的小游戏有两种起点操作：“重新开始”保留当前参数、恢复运行进度；“重置”还原全部初始设置。修改参数时暂停播放，并结束当前拖拽，便于调整后再开始。游戏将标题、业务说明和得分、下一步提示等指标集中在顶部，图形与操作区接在下方。

选择、匹配、顺序等非空间玩法可用语义操作卡：点击卡片，或用 Tab 聚焦后按 Enter/空格，触发相同的本地操作。作品可显示当前选中卡片并禁用不可用项；若卡片标有字母或数字快捷键，聚焦作品后可直接使用，快捷键只在该作品内生效。操作卡可与图形共存，也可独立呈现；空间点选和拖拽继续使用图形。

支持拖拽的场景可用鼠标、触笔或触屏移动图形；拖动会暂停播放，松手保存最后位置，离屏、失焦或关闭时取消。键盘操作由场景说明指定。拖动和普通轻触都在本地执行。

“操作说明”可展开查看场景通用操作，业务提示保留在场景旁。滑块数字显示当前实际状态，拇指按可编辑范围与步长显示；如果运行值超过编辑范围，数字仍保留真实值。

更换回答内容时，旧设置不会混入新作品。同一作品重试读取仍保留你的编辑。若上一版草稿备份失败，插件会在本页暂存最近上一版设置，并提供“导出旧草稿”；导出前保持页面打开。

新作品使用组件版本 4；组件版本 1、2、3 的已有作品可以继续读取、编辑，并按原版本导出。未知版本会保留原文件并显示诊断。

## 作品与导出

“展开”打开宿主作品页签。“更多操作”（⋯）内可复制源文、导出版本/源文/当前JSON设置，或查看源文；可用键盘、鼠标或触屏打开。菜单按当前可用空间展开，Escape关闭并回到入口。导出文件保存重现数据，运行交互仍需要本插件和兼容的 DSH。外部图片可能因来源不可用而无法显示。

主动展开时焦点进入作品，作品内的“关闭”返回展开入口；切换会话、页签或恢复作品保持你当前的操作位置。

未知组件或无效表达式会显示诊断，源文仍可复制。插件不自动发起模型修复回合；可以明确点击“修复”或发送请求，再由原会话模型修正。

## 构建与更新

0.2.0-rc.2、0.2.1-alpha.1 和 0.2.1-alpha.2 的 SDK、peer 和包版本分别锁定。换宿主时安装相应构建，继续使用原 DSH 数据目录即可保留作品。未验收的宿主版本不能通过仅修改版本声明视为支持。

IUI 1.0.0 是首个正式版本，包含此前内部迭代至 1.7 的完整功能。完整插件版本由宿主前缀与 `.iui.1.0.0` 组成，例如 `0.2.1-alpha.2.iui.1.0.0`。三个构建分别提供于本仓库的 [Releases](https://github.com/gulagala001/dsh-intelligent-ui/releases)。

当前实测为 macOS arm64 上的三个精确原版宿主，以及 alpha.2 与 OMD `0.2.1-alpha.2.omd.0.15.1` 本地候选 的共存组合。Windows、Linux、原生桌面客户端、物理触屏和多屏未完成本次同等验收；不要将浏览器布局检查或历史版本结果外推为对应平台支持。详见 [发行说明](release-1.0.0.md)。
