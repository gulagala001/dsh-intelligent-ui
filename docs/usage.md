# 使用说明

## 智能聊天

点击小＋后，插件创建新会话、选择智能聊天模式并继承当前模型。可以直接提问，例如“做个能调整人数的周末聚餐计划”“用交互图讲讲光合作用”“给我一个分账工具”。模型会选择合适的文字和控件；只需要文字的问题仍可用文字回答。

生成过程中先呈现已有部分。控件在当前生成步骤结算并读取已保存设置后启用，避免半成品动作落到旧状态。

## 普通 agent

使用 `/intelligent-ui` 或原生 `skill({name:"intelligent-ui"})`。基础资料随 skill 正文提供；图表、表单、交互与场景资料按需读取。安装插件不会替换普通 agent 的主提示词、模型、工具循环或所有工具说明。

## 操作与恢复

数字、选择、勾选、图表筛选和游戏操作都在本地执行。明确的提交按钮将所选字段和操作说明发给原会话，继续沿用 DSH 排队、取消和恢复。

控件设置自动保存。刷新、重开和宿主重启后从原会话恢复。模拟播放在恢复后暂停，点击播放才继续；离屏、后台或关闭视图会停止。

同一作品在回答与展开页签共享设置。多个标签页发生保存冲突时，当前编辑继续保留；确认保存时合并未修改的远端字段。发生错误时先看回答底部的保存状态，再选择重试。

图表可以直接点选图形或下方数据行；聚焦图形后用方向键移动、Enter 或空格选中，Escape 取消。饼图可以切换指标并隐藏分类，图例显示数值与占比。表格排序和图表筛选在展开、收回和刷新后保留。无法区分的完全重复数据行或超长行身份，其点选仅当前视图保留。

内联回答与展开页签中的同一模拟共用播放与暂停；关闭其中一处后，另一处仍可继续。全部视图离屏或进入后台后暂停，重开默认暂停。

模拟和带参数的小游戏有两种起点操作：“重新开始”保留当前参数、恢复运行进度；“重置”还原全部初始设置。修改参数时暂停播放，并结束当前拖拽，便于调整后再开始。游戏可在画布旁显示得分、下一步提示与其他指标。

支持拖拽的场景可用鼠标、触笔或触屏移动图形；拖动会暂停播放，松手保存最后位置，离屏、失焦或关闭时取消。键盘操作由场景说明指定。拖动和普通轻触都在本地执行。

“操作说明”可展开查看场景通用操作，业务提示保留在场景旁。滑块数字显示当前实际状态，拇指按可编辑范围与步长显示；如果运行值超过编辑范围，数字仍保留真实值。

更换回答内容时，旧设置不会混入新作品。同一作品重试读取仍保留你的编辑。若上一版草稿备份失败，插件会在本页暂存最近上一版设置，并提供“导出旧草稿”；导出前保持页面打开。

## 作品与导出

“展开”打开宿主作品页签。“更多操作”（⋯）内可复制源文、导出版本/源文/当前JSON设置，或查看源文；可用键盘、鼠标或触屏打开。菜单按当前可用空间展开，Escape关闭并回到入口。导出文件保存重现数据，运行交互仍需要本插件和兼容的 DSH。外部图片可能因来源不可用而无法显示。

主动展开时焦点进入作品，作品内的“关闭”返回展开入口；切换会话、页签或恢复作品保持你当前的操作位置。

未知组件或无效表达式会显示诊断，源文仍可复制。插件不自动发起模型修复回合；可以明确点击“修复”或发送请求，再由原会话模型修正。

## 构建与更新

0.2.0-rc.2、0.2.1-alpha.1 和 0.2.1-alpha.2 的 SDK、peer 和包版本分别锁定。换宿主时安装相应构建，继续使用原 DSH 数据目录即可保留作品。未验收的宿主版本不能通过仅修改版本声明视为支持。
