# Intelligent UI 使用说明

[English](usage.en.md) · [返回首页](../README.md)

## 智能聊天

鼠标移到侧栏整格"新会话"上，右侧会出现 Chat 气泡。点它会新建一个会话，切到智能聊天模式，并沿用当前模型；点格子的其他位置还是建普通会话。用键盘时 Tab 到 Chat 按 Enter；触屏和侧栏收起时入口一直显示。

直接提问就行，比如"做个能调整人数的周末聚餐计划""用交互图讲讲光合作用""给我一个分账工具"。模型会自己挑合适的文字和控件；只需要文字回答的问题，它照样用文字回答。

生成时先显示已经出来的部分。控件要等这一步生成完、读到已保存的设置后才能操作，免得你在半成品上点了按钮。

## 在普通会话里用

输入 `/intelligent-ui`，或者让模型调用 `skill({name:"intelligent-ui"})`。基础说明随 skill 一起加载，图表、表单、交互和场景的资料按需读取。装这个插件不会改普通会话的提示词、模型和工具。

## 操作和保存

数字、选择、勾选、图表筛选和小游戏都在本地运行。点作品里的提交按钮，才会把选中的内容发回原会话，之后的排队、取消和恢复都照 DSH 原来的方式。

- **自动保存**：调过的设置自动保存，刷新、重开或重启 DSH 后会恢复。模拟动画恢复后先暂停，点播放才继续；切到别处、后台或关掉视图时也会停。
- **多处同步**：同一个作品在回答里和展开页签里共用设置。多个标签页同时改出现冲突时，你正在改的内容保留，确认保存时会合并别处没冲突的字段。出错时先看回答底部的保存状态，再决定是否重试。
- **合并失败**：如果两处设置合在一起没法运行，保存会停下并说明原因。当前草稿还能继续改，刷新后也在，调整好再确认保存。
- **换了回答**：回答内容换了，旧设置不会混进新作品。如果上一版草稿没备份成功，页面上会先暂存一份，并提供 **导出旧草稿**，导出前别关页面。

## 图表

- 可以直接点图形或下方的数据行。聚焦图形后用方向键移动，Enter 或空格选中，Escape 取消。
- 饼图可以切换指标、隐藏分类，图例里显示数值和占比。
- 表格排序和图表筛选在展开、收起和刷新后都保留。
- 系列标了单位（`unit`）的柱图、折线图、面积图和散点图，会按单位分组显示，比如"元"和"GB"通过 **显示指标** 切换。没标单位的不会按名称去猜，也不会自动换算。
- 回答比较窄时，图表、示意图和场景可以 **放大图形**，按原尺寸看标注，图形区域单独滚动。点 **适应宽度** 回到全貌。放大只影响当前视图。

## 模拟和小游戏

- 回答里和展开页签里的同一个模拟共用播放状态；关掉其中一处，另一处还能接着放。全部视图都不可见时自动暂停，重新打开默认暂停。
- **重新开始** 保留当前参数，只把进度归零；**重置** 恢复全部初始设置。改参数时会先暂停、结束正在进行的拖动。
- 选择、配对、排序这类玩法可以用操作卡：点卡片，或 Tab 聚焦后按 Enter 或空格。卡片上标了字母或数字快捷键的，聚焦作品后可以直接按，只在这个作品里生效。
- 支持拖动的场景可以用鼠标、触控笔或手指拖。拖动时暂停播放，松手保存位置，切走或失焦时取消。
- **操作说明** 里能看通用操作。滑块旁边的数字显示真实的当前值；运行值超出可调范围时，数字仍显示真实值。

## 展开和导出

**展开** 会在 DSH 里打开一个作品页签，焦点进入作品，点作品里的 **关闭** 回到原处。**更多操作**（⋯）里可以复制源文、导出版本、源文或当前 JSON 设置，也可以查看源文；Escape 关闭菜单。

导出文件能重现作品数据，但要继续交互，仍需要装着本插件、版本匹配的 DSH。外部图片可能因为来源失效而显示不出来。

## 出错时

遇到不认识的组件或无效表达式，作品会显示诊断，源文仍能复制。插件不会自动让模型重做；点 **修复** 或自己发一句请求，让原会话的模型改。

新作品用组件版本 4。版本 1、2、3 的旧作品可以继续打开、编辑，并按原版本导出。不认识的版本会保留原文并显示诊断。

## 更新

用新版安装包覆盖安装，保留原来的 DSH 数据目录，作品就能接着用。见[安装指南](install.md)。
